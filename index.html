About

Who I am

I am a C# developer with hands-on experience in .NET, Unity and server-side development. At Royal Ark I work on live mobile games: gameplay mechanics, client–server interaction and a Blazor web application used by the team.

Before moving into development I spent a year and a half in manual QA on the same games, so I know how features break and how to design them so they don't. Earlier I freelanced for six years as a PHP web developer, building sites, modules and APIs for small businesses.

I care about clean architecture, performance and code that other people can read. Outside work I build open-source tools in Python, JavaScript and C#: Telegram bots, REST APIs, scrapers and front-end pages, each with tests, CI and Docker.
